# Miami Waterfront Commons — What If Calculator

Static HTML + JavaScript. No build step or server required.

## Deploy on GitHub Pages

1. Create a new **public** repository, e.g. `miami-waterfront-what-if`.
2. Upload `index.html` and `.nojekyll` to the **repository root** (not inside a subfolder). Commit the files.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then **Save**.
6. Wait a few minutes. The URL is `https://YOUR-USERNAME.github.io/miami-waterfront-what-if/`.

The cover illustration is embedded in `index.html` so no separate image is needed. All calculations run locally in the browser. The default coefficients are illustrative assumptions, not measured Miami predictions.
